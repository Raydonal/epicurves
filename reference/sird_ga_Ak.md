# Resolvent matrix \\A\_{k-1} = \Phi(t_k, t\_{k-1})\\ of interval `k`

Resolvent matrix \\A\_{k-1} = \Phi(t_k, t\_{k-1})\\ of interval `k`

## Usage

``` r
sird_ga_Ak(tr, k)
```

## Arguments

- tr:

  Object returned by
  [`sird_ga_transition()`](https://raydonal.github.io/epicurves/reference/sird_ga_transition.md).

- k:

  Integer interval index, `1, ..., n`.
