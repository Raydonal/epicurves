# Plot an ensemble fit against the observed data

Plot an ensemble fit against the observed data

## Usage

``` r
plot_ensemble_fit(fit, show_models = TRUE)
```

## Arguments

- fit:

  An `ensemble_fit` object.

- show_models:

  Logical; overlay the three individual growth-curve fits in addition to
  the ensemble curve.

## Value

A `ggplot` object.
