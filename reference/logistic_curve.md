# Logistic growth curve

Logistic growth curve

## Usage

``` r
logistic_curve(t, y0, K, gamma)
```

## Arguments

- t:

  Time.

- y0:

  Cumulative count at the start of the fitting window.

- K:

  Final epidemic size (carrying capacity).

- gamma:

  Growth rate.

## Value

Numeric vector, same length as `t`.
